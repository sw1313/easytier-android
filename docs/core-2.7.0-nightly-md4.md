# EasyTier 2.7.0 Nightly Android 适配构建 4

基于官方提交 `2abb1676b475947e46c527b57acc5f296cb48482`，提交日期为 2026-11-11。

- 提供 ARM64、ARMv7 与 x86_64 的 API 1 签名独立核心包。
- 适配新的实例管理、运行状态、远程 RPC 与配置服务器接口。
- Android 持有 TUN 文件描述符，核心借用并在停止时释放对接口的使用。
- 支持命名 WireGuard 门户客户端，1.2.7 提供相应的可视化配置和逐客户端配置查看。
- 已有 `client_cidr` 门户配置保持原有保存格式，Nightly 运行时将其转换为 `legacy-client`，使用该网段的首个可用地址。缺失的专用门户私钥会生成并保存，重连继续使用。使用旧门户的设备需要重新导入生成的 WireGuard 客户端配置。

应用最低版本为 1.2.7，包含专用门户私钥的生成与持久化、命名客户端界面以及可下载兼容包选择逻辑。后续 API 1 兼容核心可继续独立更新。选择“设置 → 核心更新 → Nightly”，下载后应用并重启。可切回稳定版并下载稳定核心。

对应源码包含 `nightly/native`、锁文件及固定提交的 `nightly/core`，构建命令见构建说明。
